# RiskOfCatan

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues on this repo; use `gh` for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical labels, name == role: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the root and ADRs under `docs/adr/` — created lazily by `/domain-modeling`. See `docs/agents/domain.md`.
